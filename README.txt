Muguet Music アイコン更新用ファイル

含まれるファイル:
- icon-192.png
- icon-512.png
- sw.js（キャッシュ名をv69へ更新）

GitHubリポジトリ muguet-music のルートに、3ファイルをアップロードして既存ファイルを置き換えてください。
その後 Commit changes を押すと、Vercelが自動デプロイします。
デプロイが Ready になったら、アプリを一度閉じて再度開いてください。
古いアイコンが残る場合は、ホーム画面のショートカットを削除してから、Chrome/Edgeで公開ページを開き直し、ホーム画面またはアプリとして追加し直してください。
